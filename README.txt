# BISO Website

Files:
- index.html — Home / Mission Control
- members.html — Members page
- style.css — Design and responsive styling
- script.js — Mobile menu, year, and demo contact form

## Run locally
Open `index.html` in a browser.

## Put it online
### GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, for example `biso-website`.
3. Upload all four files to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Choose `main` and `/ (root)`, then Save.
7. GitHub will provide your public website URL.

### Netlify
1. Create a Netlify account.
2. Choose Add new site → Deploy manually.
3. Drag the whole `biso-website` folder into the upload area.
4. Netlify will publish it and give you a public URL.

Note: the contact form is a front-end demo. It does not send email or store messages.
